# Samba Web UI

**Samba Web UI** — это современное, легкое веб-приложение, написанное на Java/Spring, для визуального управления сервером Samba (SMB/CIFS) на системах Linux.

Проект спроектирован так, чтобы обеспечить системным администраторам, инженерам DevOps и домашним пользователям простой способ настройки общих папок без ручного редактирования `smb.conf`.

---

## Ключевые возможности проекта

- 🛡️ **Zero-Agent архитектура**: Приложение может работать в Docker контейнере отдельно от файлового сервера, подключаясь по SSH без установки агентов на Linux.
- 📁 **Удобное управление общими папками**: Визуальное меню для создания, настройки, скрытия папок. Назначение прав доступа. Поддержка доменных пользователей Active Directory.
- 👥 **Управление и Доступ**: Полный цикл визуального создания, изменения и удаления Линукс пользователей, а также система Групп для массового распределения прав.
- ⚙️ **Манипуляции `[global]` секцией**: Безопасный интерфейс настройки рабочей группы SMB, логов, безопасности старых протоколов (SMB2/SMB3).
- 💾 **Автоматика и Безопасность (testparm)**: 
    - Мгновенная проверка синтаксиса `smb.conf` утилитой `testparm` при любом изменении.
    - Автоматическое создание бэкапов конфигурации в `/etc/samba/backups/`.
- 🩺 **Мониторинг Статуса**: Встроенная панель наблюдения за `smbd` и `smbstatus`, позволяющая "убивать" (kill) зависшие сессии пользователей в один клик.
- 🐳 **Docker-Ready**: Готовое решение в один контейнер с публикацией образов через автоматику Github Actions на Docker Hub.
