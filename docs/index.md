# Samba Web UI

**Samba Web UI** — это современная, легкая и безопасная панель управления файловыми серверами Samba (SMB/CIFS) под управлением Linux.

Проект спроектирован для системных администраторов, которым нужен удобный веб-интерфейс без необходимости устанавливать тяжелые панели управления на сам целевой сервер.

---

## Ключевые возможности

- 🚀 **Zero-Agent архитектура**: Управление сервером через SSH без установки агентов или демонов на хост.
- 📁 **Управление общими ресурсами (Shares)**: Создание, редактирование, настройка прав, масок файлов и гостевого доступа.
- 👥 **Управление пользователями**: Добавление пользователей Linux/Samba, сброс паролей и удаление учетных записей.
- ⚙️ **Глобальные настройки `[global]`**: Управление рабочей группой, режимами безопасности, протоколами SMB2/SMB3 и сетевыми адаптерами.
- 🛡️ **Безопасность и автоматические бэкапы**:
    - Валидация через `testparm` перед применением изменений.
    - Автоматические снимки конфигурации `/etc/samba/smb.conf` с возможностью отката в один клик.
- 🐳 **Готовность к Docker**: Развертывание в изолированном контейнере за пару минут.
