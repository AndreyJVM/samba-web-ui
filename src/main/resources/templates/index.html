Подготовка Samba-сервера

Перед подключением выполните следующие команды на вашем Linux-сервере под пользователем root или через sudo:

  1. Убедитесь, что Samba установлена:
    sudo apt update && sudo apt install -y samba (Ubuntu/Debian)
  2. Создайте системного администратора для панели:
    sudo useradd -m -s /bin/bash samba-admin
    sudo passwd samba-admin
  3. Добавьте пользователя в базу Samba:
    sudo smbpasswd -a samba-admin
  4. Настройте права sudo без пароля для команд управления:
    Создайте файл /etc/sudoers.d/samba-web-ui: 
    sudo visudo -f /etc/sudoers.d/samba-web-ui
    Вставьте в него строку одной строкой: 
    samba-admin ALL=(ALL) NOPASSWD: /usr/bin/pdbedit, /usr/bin/smbpasswd, /usr/sbin/useradd, /usr/sbin/userdel, /usr/bin/chpasswd, /usr/bin/passwd, /usr/sbin/service smbd restart, /bin/systemctl restart smbd, /usr/bin/systemctl restart smbd, /bin/mv, /bin/cat, /bin/mkdir, /bin/chmod, /bin/chown, /usr/bin/mkdir, /usr/bin/chmod, /usr/bin/chown
Готово! Теперь введите IP сервера, логин samba-admin и назначенный пароль в форму подключения.
