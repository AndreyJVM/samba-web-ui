Подготовка Samba-сервера
  1. Быстрая настройка через скрипт (рекомендуется): 
    wget -qO- https://raw.githubusercontent.com/AndreyJVM/samba-web-ui/master/scripts/setup-samba-server.sh | sudo bash
    2. Ручная настройка:
  2. Установка Samba: sudo apt install -y samba
  3. Создание пользователя: sudo useradd -m -s /bin/bash samba-admin && sudo passwd samba-admin
  4. Добавление в Samba: sudo smbpasswd -a samba-admin
  5. Настройка прав доступа в /etc/sudoers.d/samba-web-ui: 
    samba-admin ALL=(ALL) NOPASSWD: /usr/sbin/useradd, /sbin/useradd, /usr/sbin/userdel, /usr/bin/kill, /sbin/userdel, /usr/sbin/chpasswd, /usr/bin/chpasswd, /usr/bin/smbpasswd, /usr/bin/pdbedit, /usr/bin/tail, /bin/df, /usr/bin/df, /bin/systemctl, /usr/bin/systemctl, /bin/cat, /usr/bin/cat, /bin/mv, /usr/bin/mv, /bin/mkdir, /bin/cp, /usr/bin/cp, /bin/rm, /usr/bin/rm, /usr/bin/mkdir, /bin/chmod, /usr/bin/chmod, /bin/chown, /usr/bin/chown, /usr/bin/smbstatus, /usr/bin/systemctl, /bin/kill, /usr/bin/tail is-active smbd, /usr/sbin/groupadd, /sbin/groupadd, /usr/sbin/groupdel, /sbin/groupdel, /usr/bin/gpasswd
