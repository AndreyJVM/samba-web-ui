Подготовка Samba-сервера
  1. Установите Samba: sudo apt install -y samba
  2. Создайте пользователя: sudo useradd -m -s /bin/bash samba-admin && sudo passwd samba-admin
  3. Добавьте в Samba: sudo smbpasswd -a samba-admin
  4. Разрешите команды без пароля в /etc/sudoers.d/samba-web-ui: 
    samba-admin ALL=(ALL) NOPASSWD: /usr/sbin/useradd, /sbin/useradd, /usr/sbin/userdel, /sbin/userdel, /usr/sbin/chpasswd, /usr/bin/chpasswd, /usr/bin/smbpasswd, /usr/bin/pdbedit, /usr/bin/tail, /bin/df, /usr/bin/df, /bin/systemctl, /usr/bin/systemctl, /bin/cat, /usr/bin/cat, /bin/mv, /usr/bin/mv, /bin/mkdir, /bin/cp, /usr/bin/cp, /bin/rm, /usr/bin/rm, /usr/bin/mkdir, /bin/chmod, /usr/bin/chmod, /bin/chown, /usr/bin/chown, /usr/bin/smbstatus, /usr/bin/systemctl, /usr/bin/tail is-active smbd
