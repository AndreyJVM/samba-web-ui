# Docker Sandbox for Samba Web UI 🐳

Эта директория содержит конфигурацию для запуска тестового окружения (Sandbox), чтобы разработчики могли проверять функциональность без установки Samba и SSH на свой рабочий компьютер (например, на Windows/Mac).

## Как это работает?

Мы используем `docker-compose.yml` в корне проекта, который собирает кастомный образ на базе `ubuntu:22.04`.
Внутри этого образа запущены:
- **SSH Сервер** (на порту 22 внутри контейнера, и доступен на хосте как `2222`).
- **Samba (smbd, nmbd)** (на портах 139, 445 внутри контейнера).

Также внутри контейнера автоматически:
- Создан системный Linux-пользователь `admin` с паролем `admin` и полными правами Sudo.
- Создан Samba-пользователь `admin` с паролем `admin`.
- Настроен базовый конфигурационный файл `/etc/samba/smb.conf` и создана публичная папка `/srv/samba/public`.

## Запуск песочницы

Выполните в корне проекта:
```bash
docker compose up -d
```

Затем в форме авторизации `Samba Web UI` (запущенного через Spring Boot или React dev server) введите следующие доступы:

- **Host (IP Address)**: `127.0.0.1` или `localhost`
- **SSH Port**: `2222`
- **Username**: `admin`
- **Password**: `admin`

*(Приложение подключится по SSH к Docker-контейнеру на порт 2222 и дальше будет парсить файлы конфигурации и управлять Samba так, будто оно запущено на реальном сервере!)*
